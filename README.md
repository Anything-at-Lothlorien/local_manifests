# Local Manifest for Xiaomi Redmi Note 10 Pro/Pro Max
This repository contains the manifest for building a custom ROM for the Xiaomi Redmi Note 10 Pro/Pro Max.
---

## How to use:
1. Initialize your repo environment and then clone the local manifest directly:

   ```bash
   repo init -u <manifest-url>
   
   git clone https://github.com/Lothlorien-playground/local_manifests.git -b sixteen .repo/local_manifests

2. Sync the repositories:
repo sync
